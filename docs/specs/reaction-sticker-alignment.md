# Reaction 与 sticker 需求对齐

状态：访谈中；尚未进入实现。

需求来源：当前 fork 的 GitHub Issues #3（reaction）与 #4（sticker）。
术语见根目录 `GLOSSARY.md`。

## 已确认：reaction 去重范围

- 以“目标 Bot 消息＋操作者”为去重范围，只接受首次添加。
- 同一操作者在同一条消息上换表情、删除后重加，均不再次触发。
- 不同操作者分别处理；同一操作者对另一条 Bot 消息的首次添加仍可触发。

场景：甲在消息 A 上先加 OK、再加 NO，仅 OK 被接受；乙在消息 A 上加 OK、甲在消息 B 上加 OK，分别可被接受。

## 待对齐

- 去重记录在 Bridge 重启后的有效性。
- 被策略拒绝或处理失败的添加是否消耗首次机会。
- 接受后的回执与运行反馈。
- Sticker 图片透传的失败降级与验收边界。
